# Justable brand assets

- Use the black assets or `*-light.*` variants on light surfaces.
- Use the white assets or `*-dark.*` variants on dark surfaces.
- Recommended README artwork: `readme/justable-readme-light.png` (or the dark equivalent).
- Social previews: `social/justable-social-light.png` and `social/justable-social-dark.png`.
- Favicons: `favicon/favicon.ico`, plus 16 px, 32 px, and 48 px PNGs.

The mark is supplied with its original geometry and must not be distorted, recoloured, or combined with other symbol elements.

## macOS app icons

Use [the light ICNS](macos/justable-macos-light.icns) by default, or [the dark ICNS](macos/justable-macos-dark.icns) as an alternative. See [macOS usage and validation](macos/README.md) and [the preview](macos/justable-macos-preview.png).
